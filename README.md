\# Analema Solar Interactivo



Aplicación Streamlit para visualizar analemas solares, comparar ciudades y seleccionar ubicaciones desde un mapa interactivo.



\## Ejecutar online



Puedes ejecutar esta app directamente en Streamlit Cloud:



1\. Sube este repositorio a GitHub.

2\. Ve a https://share.streamlit.io

3\. Selecciona tu repositorio.

4\. Elige el archivo `app.py` como entrypoint.



\## Ejecutar en local



```bash

pip install -r requirements.txt

streamlit run app.py
